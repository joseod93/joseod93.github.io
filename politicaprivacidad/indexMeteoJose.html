Política de Privacidad MeteoJose

Esta Política de Privacidad describe cómo la aplicación MeteoJose trata la información cuando utiliza el servicio y le informa sobre sus derechos de privacidad.

Nos tomamos muy en serio su privacidad y la protección de sus datos. MeteoJose es una aplicación que muestra los datos de una estación meteorológica casera y no accede a datos de usuario personales ni sensibles.

Información que Recogemos

MeteoJose no solicita ni recoge información personal como nombre, dirección, número de teléfono, correo electrónico, contactos, fotos, archivos ni ubicación. No es necesario crear una cuenta ni iniciar sesión para usar la aplicación.

Permisos de la Aplicación

La aplicación solo utiliza los siguientes permisos:

  • Acceso a Internet: necesario para descargar y mostrar los datos meteorológicos.
  • Estado de la red: para comprobar si hay conexión y avisar al usuario cuando no la hay.

La aplicación no utiliza la cámara, el micrófono, la ubicación, los contactos ni el almacenamiento del dispositivo.

Datos Técnicos de Conexión

Para mostrar la información, la aplicación carga una página web alojada en GitHub Pages que consulta los datos de la estación en un servidor propio. Como ocurre con cualquier visita a una página web, estos servidores pueden registrar de forma automática datos técnicos de la conexión, como la dirección IP, la fecha y hora de la petición o el tipo de navegador.

Estos datos se utilizan únicamente para el funcionamiento técnico y la seguridad del servicio. No se utilizan para identificar a los usuarios, crear perfiles ni con fines publicitarios.

Uso de la Información

Al no recoger datos personales ni sensibles, no hacemos uso alguno de dicha información. Los datos meteorológicos mostrados proceden de la estación y de fuentes públicas, y no están relacionados con el usuario.

Compartir Información

No vendemos ni compartimos ningún tipo de datos de usuario personales ni sensibles con terceros.

Servicios de Terceros

Algunos contenidos de la página mostrada por la aplicación se sirven desde proveedores externos, como GitHub Pages (alojamiento) o redes de distribución de contenido para bibliotecas de gráficos. Estos proveedores pueden procesar datos técnicos de conexión de acuerdo con sus propias políticas de privacidad.

Seguridad de los Datos

La aplicación está diseñada para no recoger, almacenar ni compartir datos de usuario. Las conexiones con los servidores se realizan, siempre que es posible, mediante protocolos seguros.

Conservación y Eliminación de Datos

Dado que no recogemos ni almacenamos datos personales de los usuarios, no aplicamos políticas de conservación o eliminación de dichos datos. Los registros técnicos de los servidores se conservan solo el tiempo necesario para su funcionamiento.

No dirigido a menores

Nuestro Servicio no está dirigido a personas menores de 13 años. No recopilamos a sabiendas información de identificación personal de menores de 13 años. Si usted es un padre o tutor y cree que su hijo nos ha proporcionado Datos Personales, por favor contáctenos.

Funciones de Salud

Nuestra aplicación no tiene ninguna función relacionada con la salud. No está diseñada para monitorear, diagnosticar, tratar, curar ni prevenir ninguna condición de salud o enfermedad.

Publicidad

Nuestra aplicación no muestra publicidad. Ofrecemos un entorno libre de anuncios para todos los usuarios.

Propósito de la Aplicación

MeteoJose es una aplicación personal que muestra los datos de una estación meteorológica casera (temperatura, humedad, presión y luminosidad, entre otros). Los datos se ofrecen a título informativo y sin garantía de exactitud.

Cambios en esta Política

Podemos actualizar esta Política de Privacidad cuando sea necesario para reflejar cambios en la aplicación o en los requisitos legales aplicables. Cualquier cambio se publicará en esta página.
